# Car Price Prediction with Machine Learning

**Project:** Car Price Prediction with Machine Learning

## Objective

Build a machine learning regression model to predict the selling price of used cars based on features such as brand, car age, mileage, fuel type, transmission, engine, max power, and other relevant features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Steps Performed

1. Dataset collection
2. Data cleaning
3. Handling missing values
4. Removing duplicate records
5. Feature engineering
6. Exploratory Data Analysis
7. Encoding categorical variables
8. Correlation analysis
9. Train-test split
10. Linear Regression model
11. Random Forest Regression model
12. Model evaluation using MAE, RMSE and R²
13. Feature importance analysis
14. Car price prediction

## Best Model

Random Forest Regression performed better than Linear Regression based on the evaluation results.

## Result

The model can predict the estimated selling price of a used car based on the provided vehicle details.

## Conclusion

This project demonstrates how machine learning can be used to predict used car prices. After data preprocessing, exploratory analysis, feature engineering, and model training, Random Forest Regression provided strong predictive performance and was selected as the final model.
